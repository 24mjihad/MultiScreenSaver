# MultiScreenSaver

MultiScreenSaver is a lightweight Windows multi-monitor background app that lets you run a screen saver on selected displays while leaving other displays on the normal desktop. It is designed for setups where each monitor may need a different idle behavior.

## Features

- Enable or disable saver mode per monitor.
- Keep one monitor active while another monitor runs a saver.
- Choose a different screen saver for each monitor.
- Use the built-in animated saver or supported Windows `.scr` screen saver files.
- Preview enabled monitors instantly without waiting for idle timeout.
- Dismiss only the saver on the monitor receiving input.
- Save monitor settings and idle timeout in the current user profile.


## Download

Download and run the executable at `bin/Debug/MultiScreenSaver.exe` in this repository.

No extra setup is required beyond opening that file on a supported Windows machine. If Windows reports a missing runtime, install the Microsoft Visual C++ 2022 Redistributable and run the executable again.
